# Repo conventions

## Git

### Commit style

Do not add any "Co-authored-by" or AI attribution lines to commit
messages.

## Assumed assistant

This template assumes Claude Code specifically, not a generic "AI coding
assistant" — docs throughout say "Claude," and `study/CLAUDE.md` relies
on Claude Code's auto-load behavior for onboarding. If a fork of this
template is ever used with a different tool, adapting the wording and the
auto-load mechanism is that user's responsibility, not something this
template hedges for by default.
