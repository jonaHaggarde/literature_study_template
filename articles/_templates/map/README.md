# map

A light scouting pass over the whole field, read at the `map` gate. Its job is to let the
user see the shape of the field before the expensive reading starts, and to choose where
the review goes deep.

| | |
|---|---|
| Gate | `map` (light) |
| Written from | the definition and `scope.md`; catalog entries and `study/leads.md` without full notes or method cards (titles, abstracts, citation links) |
| Feeds | the review, which starts from this taxonomy and goes deep only where the user chose; its coverage view is measured against this article |
| Style | mostly figures and tables, a sentence or two of prose per section |
| Contains no | decisions. The depth proposal is a proposal; the user's choice goes in the gate record |

**Varies per project:** the number of taxonomy axes; the vocabulary section is dropped for a
field with one vocabulary.

**To check before this is built for real:** whether the engine can hold catalog entries
without notes, or whether `leads.md` plus a family column is enough for scouting.
