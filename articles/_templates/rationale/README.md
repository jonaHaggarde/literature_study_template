# rationale

Chooses a concept, or two or more to be tested, by engineering rationale: criteria,
assumptions, priorities. Derivations and equations belong in the specification articles.

| | |
|---|---|
| Gate | `concept` (full) |
| Written from | the definition, the requirements (if the project has them) and the review |
| Feeds | one `specification-<name>` article per chosen concept |
| Length | no fixed number; roughly 8 to 15 pages is the expectation, not a target |
| Contains no | derivations; options that were never looked at presented as examined |

**Rules:** every concept investigated and not chosen is described with the reason it was not
chosen. When two or more concepts remain, the trial plan and later the trial results go in
the trials section, as new versions, and the concept gate is checked again after the trials.

**Varies per project:** the trials section exists only when two or more concepts remain.
